# Dashboard Financeiro · Landing Page

Landing page do Dashboard Financeiro, recriada a partir de https://dashboardfinanceiro.com/comprar/ com identidade visual inspirada em https://www.oratry.com.br/.

- `index.html`: página completa (HTML, CSS e JS inline)
- `assets/img/`: imagens do produto, depoimentos e foto da criadora

Para visualizar, abra `index.html` no navegador. Para publicar, sirva a pasta como site estático (GitHub Pages, Vercel, Netlify).

Antes de publicar: cole o snippet do seu Meta Pixel no `<head>` (há um comentário indicando o lugar).
